# FunnyTrans

遇到框选文字、识别原文或查看译文的问题，或希望 FunnyTrans 增加某个功能？可以先[查看已知问题和建议](https://github.com/funnies-top/funnytrans-feedback/issues)，也可以[提交反馈](https://github.com/funnies-top/funnytrans-feedback/issues/new?template=feedback.yml)。
